FitPath mobile-first refinement

This is your uploaded project with improved Today and Log pages.
1. Back up your original fitpath folder.
2. Extract this archive and open fitpath in VS Code.
3. In the fitpath directory run npm install (if needed), then node server.js.
4. Open http://localhost:3000

Data remains in browser localStorage (fitpathPlan and fitpathLogs).
No account or cloud synchronization is provided.
