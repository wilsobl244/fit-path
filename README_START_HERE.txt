FitPath dark mobile upgrade

1. Back up your current fitpath folder.
2. Open this fitpath folder in VS Code.
3. In terminal run: npm install ; npm start
4. Open http://localhost:3000
5. Use moon/sun button to switch themes. Dark is the default.

Existing plan and workout history are saved in browser localStorage and remain tied to the same browser/origin. This is a visual and usability upgrade, not a cloud account system. No step/heart-rate/calorie sensors are connected, so none are fabricated.
